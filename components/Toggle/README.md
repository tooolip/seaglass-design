Native checkboxes restyled as switches and checkboxes; on is the solid `accent`. Classes: `.switch` (add `role="switch"`), `.check`, `.toggle-row`.

**You provide:** an `input type="checkbox"` inside or tied to a `label`; `role="switch"` for switches.

**Use it for:** switches for settings that apply right away; checkboxes for choices submitted later or multi-select lists.

**Do**
- Put the switch at the end of the row and the label at the start.
- Phrase the label as the setting: "Email updates".

**Don't**
- Use a switch in a form that has a Save button; use a checkbox.
