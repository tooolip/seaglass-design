What a list, grid or search shows when it has nothing yet: what will appear, and the first step to take. Classes: `.empty`, `.empty-icon` (with `.pebble` and a hue), `.empty-title`, `.empty-text`.

**You provide:** a title that names what is missing, one sentence on what will appear or how to fix a search, and one primary action (plus at most one secondary).

**Use it for:** first use, cleared filters, no search results, an error that left nothing to show.

**Do**
- Write the specific thing: "No projects yet", "No matches for “tide”".
- Keep it left-aligned with the content it replaces.

**Don't**
- Leave a blank area, or show only an illustration.
- Write "Oops!" or apologize; say what happened and what to do.
